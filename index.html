Календарь пожарной активности

Объединяет данные спутниковых датчиков (демо: имитация MODIS/VIIRS) в единый календарь по выбранной области — для оценки сезонности и аномальных периодов.

Область интереса

Перетащите по сетке (широта/долгота), чтобы выделить прямоугольную область, или введите координаты вручную.

Демо-режим: данные симулируются локально (сезонная модель + шум), чтобы показать интерфейс без бэкенда. Чтобы подключить реальные данные, нужен сервер-прокси, который дергает NASA FIRMS Area API (архив активных очагов MODIS/VIIRS с 2000/2012 г.) по bbox и диапазону дат, кладёт нормализованные записи (дата, координаты, confidence, датчик) в БД с пространственным индексом (PostGIS/H3), и отдаёт этому фронтенду те же агрегаты по дням — тогда календарь и сезонность заполнятся настоящими цифрами.
